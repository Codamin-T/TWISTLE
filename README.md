## Prerequisites & Environment
To run the application, you need the following installed on your system:
* **Java SDK 21**
* An IDE with Maven support (this project used **JetBrains IntelliJ IDEA**)

### Project Structure
* **Source folder:** `src/main/java`
* **Resource folder:** `src/main/resources`

### Environment Configuration
The application requires environment properties to connect to the database. You need the following variables in your local environment:
